El sistema con el que llevo mi búsqueda de trabajo, como plantilla limpia. Skills de Claude Code
postulan a un cargo, adaptan un CV de una página, revisan ofertas nuevas y preparan entrevistas.
Cada dato del CV sale de un banco de bullets verificados, y un script compara las palabras clave
del aviso con el borrador. Un archivo de memoria convierte cada corrección en una regla. Ya
produjo decenas de postulaciones reales. El último botón lo aprieto yo.

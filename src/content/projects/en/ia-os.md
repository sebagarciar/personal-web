The system I run my job search on, as a clean template. Claude Code skills apply to a job, tailor
a one-page CV, scan new postings and prepare interviews. Every CV claim traces to a bank of
verified bullets, and a script checks the ad's keywords against the draft. A memory file turns
each correction into a rule. It has produced dozens of real applications. I press the last
button myself.

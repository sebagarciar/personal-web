The system I run my work on, as a clean template. One memory file turns each correction into a
rule that every session loads. Skills on top of it apply to a job, tailor a one-page CV, scan new
postings, prepare interviews and write in my voice. Every CV claim traces to a bank of verified
bullets, and a script checks the ad's keywords against the draft. It has produced dozens of real
applications. I press the last button myself.

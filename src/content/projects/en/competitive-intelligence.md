An academic project for an AI for Business class, built on public sources only.
It watches Chanel, Dior and Gucci across **7** ingestion sources, including the
Grok API for X, then clusters what it finds into events and trends and writes a
weekly brief. Embeddings and classification run locally, so a run costs nothing.
